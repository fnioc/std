# Judge — di2 scope/lifetime blackbox

## 1. VERDICT: **AMEND** (hold the architecture, repair the contract text, close four named gaps before freeze)

The attack did not break the core. Every claimed internal contradiction was refuted on the doc's own text (pre/post-order, hoist probe, descriptor-less bypass, interleaved-feed LIFO, ALS, per-graph expressibility), and the defense's readings check out against the requirements file. The three rivals each self-disqualify as replacements: Placement Table cannot express the lambda-datum lifetimes the doc explicitly blesses and deletes IoC-on-the-container, which is owner-ruled; Ambient Extent's own first falsifier fires (awaits are gather-confined, every gather→realize path is an engine-owned sync call, so it collapses to threading with different delivery); LayerScope is closed-world against a container whose surface is open templates, construct-on-miss, `getServices`, and `additionalDescriptors` — its own census falsifier counts ≥4 hits. But one finding is confirmed outright and is a freeze blocker (library portability, ledger 6), the disposal ledger owes four contract rulings the attack correctly located, and the doc needs roughly a dozen cheap text pins where the attackers found genuine ambiguity that a third-party model author would fall into. Worth noting for prioritization: the port's live registration surface uses exactly one lifetime literal today (`'singleton'`, 14 sites) — the blocker is the common path, not an exotic one.

## 2. CONFIRMED WEAKNESSES (ranked)

**W1 — BLOCKER: libraries have no portable lifetime spelling, and the portable spelling (omission) means transient** (finding 16, CONFIRMED; folds in the bivariance residue of 15). TS2428 kills the re-constrain arm permanently; an oblivious `(m) => m` configure function under the default model silently converts `IMemoryCache`/`ILoggerFactory`/`IOptions` monitors to per-injection instances with no error anywhere — the governing principle inverted at the ecosystem's most common spelling. **Amendment:** settle ledger 6 before freeze with a small well-known lifetime vocabulary in di.core (Placement-shaped) that every model declares a mapping for; reserve only the model's declaration hook as the joint. Simultaneously rule the augmentation convention for model-typed manifests: per-function generic `this: Manifest<L>`, never `Manifest<any>`/`Manifest<string>`.

**W2 — The canonical cache key is unstated and the one stated sentence is wrong as read** (findings 1, 11, 35 converge). "The cache key is the as-requested type" is doing anti-`Promise<T>` work, but read literally it collapses multi-registrations and splits `getService`/`getServices` storage — every third-party model is one reasonable choice from silent duplication or aliasing. **Amendment:** pin the key as descriptor-composed (the notes' `(identifier, slot)` material, argued on its own merits), reword the sentence, and hand the door a per-descriptor **readonly view** carrying the correct address, the datum, and the disposal vocabulary — one fix serving three findings.

**W3 — The disposal design (ledger 4) owes four contract rulings and must be marked pre-freeze on its contract half** (findings 2, 5, 10, 36). (a) dispose landing between gather and write-back leaves an instance neither stored nor released — rule that a disposed door's write-back routes the orphan through release, and that `disposeAsync` quiesces the model's own outstanding set (it observes every make, so it can); (b) construct-on-miss disposables: "caller-owned" reaches no caller — pin cascade-from-owning-instance; (c) root-resolved transient tracking is the autofac root-leak imported undispositioned — disposition it explicitly (default model tracks only disposal-vocabulary-bearing descriptors, or holds weakly); (d) a door that throws after observing makes owns unwinding its own feed — state it.

**W4 — The observation seam answers "joint, nowhere"** (finding 20). Boxes minted inside a model's own `createScope` factory escape any wrapping observer, so a generic instrumented engine is not fully writable; by the doc's own foreclosure discipline this is a gap to fix before freeze. **Amendment:** contract that child-box minting routes through a wrappable point (or add a read-only make/hit observer arm), plus `model.describe(): Json`.

**W5 — Engine-side hardening bundle, all additive, no surface change** (findings 29, 30, 32, 35, 36). Adopt the lot: `Object.freeze` descriptors at manifest build (enforces "metadata never holds state"); `disposed` latch on the engine-minted provider, with the contract sentence split so the loud-error clause stops reading as an engine guarantee; at-most-once + epoch fence inside the engine-minted factory closure; `ScopeModelError` attribution wrap around door calls; unconditional nullish-return check + dev-mode `WeakMap<instance, Type>` alias guard.

**W6 — createScope is required but unasserted, and naive option-2 options merging is program-global** (findings 7, 21). **Amendment:** `Engine.validate` asserts the well-known address survived build; ledger 1 resolves toward the uniform address with the options type delivered **off the engine choice** (the dependency direction already ruled for the manifest generic), not by global declaration merging.

**W7 — Record/text repairs** (findings 3, 6/14, 12, 17, 18, 19, 22, 8, 13). Strike the stale "Contract delta: write-back RETURNS…" sentence (mechanism lives inside the returned promise); resolve the in-flight-map divergence toward the doc (adopt-or-store only; if the `outstanding` arm ever ships, rejection-eviction is a requirement of it); pin the `asValue` carve-out (a value presents no make, hence no datum — one clause); name the completion brand `withLifetime_required` so the strict-engine error names the missing step; widen the model's `undefined`-admissibility flag to `admits(datum)` at registration; write down the priced consequence that routing `undefined`-datum sites through the door forecloses the plan-time never-caches specialization (G1 below is the recovery); require the default model to carry a sync in-progress sentinel (re-entrant construction throws a named error, not a stack overflow); add the latebound note (a captured closure is a scope-lifetime handle) and sharpen the adopt-or-store honesty sentence (losers construct whole transient subtrees, not "instances").

- ALS breaks across the gather (27) — factually wrong about AsyncLocalStorage semantics.
- Descriptor-less sites doc-vs-brief disagreement (31) — doc rules bypass unambiguously; the branch already exists in code.
